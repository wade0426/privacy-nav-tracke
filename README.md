# 導航與移動軌跡紀錄App

一款專注於隱私保護的導航與移動軌跡記錄應用程式，讓您輕鬆追蹤及分析自己的移動足跡。

## 系統特色

- **隱私權保護**：不收集使用者的任何個人資料，確保使用者的隱私權不受侵犯
- **本地資料儲存**：所有定位紀錄將儲存在本機上，方便使用者回顧自己的歷史足跡
- **足跡分析**：計算出停留最久的區域，提供更多的足跡資訊給使用者
- **操作簡單**：介面簡潔直觀，適合所有年齡層使用者

## 主要功能

### 主畫面功能
- 定位與導航
- 自動與手動新增標記點
- 移動軌跡自動記錄
- 停車位置標記
- 自動載入當日歷史資料

### 歷史紀錄查詢
- 查詢歷史移動路徑
- 分析各點停留時間
- 以圓圈標示停留最久的位置
- 刪除指定歷史資料

### 個人化設定
- 自訂線條顏色與顯示方式
- 快捷線條顏色選擇
- 自訂界面元素顯示

## 系統架構

應用程式採用模組化設計，主要功能區塊包括：
- 足跡紀錄（自動/手動）
- 導航功能（多種模式）
- 資料載入與管理
- 查詢與分析功能
- 使用者設定
